# Data Engineer
## What the role does
Builds dependable systems that collect, transform, validate, and serve data.
## Typical responsibilities
Create pipelines, model warehouse data, enforce quality checks, and monitor scheduled workloads.
## Core technical skills
SQL, Python, data modeling, testing, Linux fundamentals, and basic distributed-systems concepts.
## Common technologies
For an entry-level path, start with PostgreSQL, Python, dbt, Git, Docker, and one orchestrator such as Airflow. Learn Spark after the foundations justify it.
## Useful academic foundations
Databases, algorithms, operating systems, and software engineering.
## Typical beginner projects
Ingest public files into PostgreSQL, transform them with dbt, test them, and schedule the flow.
## Related roles
Analytics Engineer, Backend Engineer, ML Engineer.
## Possible transitions
Backend developers can transition through SQL, data modeling, and pipeline reliability.
## What type of student may enjoy this role
Students who value dependable infrastructure and clean, usable data.
