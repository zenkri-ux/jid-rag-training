# Backend Engineer
## What the role does
Builds server-side application logic, APIs, data access, and integrations.
## Typical responsibilities
Design endpoints, enforce business rules, test services, and improve reliability and performance.
## Core technical skills
One backend language, HTTP, databases, testing, security fundamentals, and Git.
## Common technologies
Python with FastAPI, Java with Spring, Node.js, PostgreSQL, Redis, and Docker.
## Useful academic foundations
Algorithms, databases, networks, operating systems.
## Typical beginner projects
A tested REST API with authentication boundaries and a relational database.
## Related roles
Full-Stack Developer, Platform Engineer, AI Engineer.
## Possible transitions
Can move toward AI engineering by adding model integration and evaluation.
## What type of student may enjoy this role
Students who like system logic more than visual interface work.
