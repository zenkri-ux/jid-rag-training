# AI Engineer
## What the role does
Builds AI capabilities into reliable products, connecting models with data, APIs, evaluation, and monitoring.
## Typical responsibilities
Prototype model behavior, build inference services, evaluate quality, and collaborate with product and data teams.
## Core technical skills
Python, software engineering, ML fundamentals, APIs, data handling, evaluation, and responsible-AI basics.
## Common technologies
PyTorch, scikit-learn, FastAPI, Docker, Git, SQL, and vector databases for suitable retrieval applications.
## Useful academic foundations
Probability, linear algebra, algorithms, databases, and software design.
## Typical beginner projects
A cited document assistant with an evaluation set; an image classifier exposed through an API.
## Related roles
Machine Learning Engineer, Data Scientist, Backend Engineer.
## Possible transitions
Backend or data engineers can transition by adding ML foundations and model evaluation.
## What type of student may enjoy this role
Students who enjoy both experimentation and shipping maintainable software.
