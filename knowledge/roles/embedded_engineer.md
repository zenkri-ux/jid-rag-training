# Embedded Systems Engineer
## What the role does
Develops software that interacts directly with constrained hardware and physical devices.
## Typical responsibilities
Write firmware, integrate sensors, debug timing and communication, and test hardware-software behavior.
## Core technical skills
C/C++, microcontrollers, digital electronics, debugging, real-time concepts, and communication protocols.
## Common technologies
STM32, ESP32, PlatformIO, FreeRTOS, oscilloscopes, I2C, SPI, UART, and CAN.
## Useful academic foundations
Computer architecture, electronics, signals, control, and operating systems.
## Typical beginner projects
A sensor node with structured logging and a documented communication protocol.
## Related roles
IoT Engineer, Robotics Engineer, Edge AI Engineer.
## Possible transitions
Electrical engineers add firmware; software engineers add electronics and real-time constraints.
## What type of student may enjoy this role
Students who like programming close to hardware and debugging physical systems.
