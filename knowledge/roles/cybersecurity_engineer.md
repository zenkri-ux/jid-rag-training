# Cybersecurity Engineer
## What the role does
Reduces technical risk by designing, testing, monitoring, and improving system defenses.
## Typical responsibilities
Threat-model systems, harden configurations, investigate alerts, and automate repeatable checks.
## Core technical skills
Networks, operating systems, scripting, identity, web security, and evidence-based risk reasoning.
## Common technologies
Linux, Python, Wireshark, SIEM platforms, vulnerability scanners, and cloud security controls.
## Useful academic foundations
Networks, operating systems, cryptography fundamentals, and software engineering.
## Typical beginner projects
Build a small lab, document its threat model, and detect a controlled suspicious event.
## Related roles
Security Analyst, Application Security Engineer, Cloud Security Engineer.
## Possible transitions
System, network, and software engineers can specialize by adding security methods and practice.
## What type of student may enjoy this role
Students who are curious, methodical, and comfortable thinking like both builder and adversary.
