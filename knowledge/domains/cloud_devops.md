# Cloud and DevOps
## Scope
Cloud engineering focuses on platforms and managed infrastructure. DevOps is a collaborative and technical approach to improving software delivery and operations; it is not merely a tool list.
## Six-month exploration path
Months 1–2: Linux, networks, Git, and scripting. Months 3–4: containers and CI/CD around one small API. Months 5–6: infrastructure as code, observability, deployment, and a written incident review.
## Evidence of skill
A small system with automated tests, repeatable deployment, health checks, dashboards, and documented failure handling is stronger evidence than many disconnected tutorials.
