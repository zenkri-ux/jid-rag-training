# Artificial Intelligence and Machine Learning
## Scope
AI is a broad field concerned with systems performing tasks associated with intelligent behavior. Machine learning is one approach: systems learn patterns from examples rather than receiving every rule explicitly.
## Study priorities
Build Python and software fundamentals, then probability, linear algebra, data practice, model evaluation, and responsible deployment.
## Adjacent paths
AI Engineer emphasizes product integration; ML Engineer emphasizes the model lifecycle; Data Scientist emphasizes analysis and decisions; Edge AI combines learned models with constrained hardware.
## Limitations to remember
Models can fail outside evaluated conditions. Fluent output is not proof, and retrieval provides context rather than guaranteeing correctness.
